# Языки интерфейса

Интерфейс поддерживает русский (`ru`), узбекский в латинице (`uz`) и английский (`en`). Переключатель доступен на лендинге, при входе, оформлении подписки и в рабочем пространстве. Выбор сохраняется в `localStorage` под ключом `aniq-language`; неизвестный код заменяется на `ru`.

Переключение применяется без перезагрузки к навигации, формам, ошибкам, клиническим панелям, уведомлениям, инструкциям и FAQ, подписке и управлению платформой. Поля форм и черновики сохраняются. Уже показанные ошибки валидации пересчитываются на новом языке; нетронутые поля не получают новых ошибок.

## Поддержка переводов

- `frontend/src/i18n.ts` объединяет словари и обновляет язык HTML, заголовок страницы и описание.
- Базовые переводы: `baseTranslations.ts`, `baseEnglish.ts`; дополнительные общие подписи: `interfaceTranslations.ts`.
- Клинические, платёжные, лендинговые и прочие словари находятся в соответствующих `*Translations.ts`. Каждый новый ключ добавляется во все три языка.
- `guideContent.ts` содержит инструкции и FAQ для всех 13 разделов.
- `LocaleProvider.tsx` переключает Ant Design и сообщения валидации; `LocalizedForm.tsx` обновляет существующие ошибки без сброса формы.
- `api/client.ts` показывает локализованные ошибки по стабильным кодам API. Неизвестная ошибка получает переведённое пояснение и диагностический код. Тексты внутренних сообщений сервера не подставляются в интерфейс.
- `dates.ts` использует часовой пояс Asia/Tashkent. Для узбекских месяцев предусмотрены названия без зависимостей от неполных браузерных таблиц локалей.

Стандартные названия и описания тарифов переводятся только при совпадении с исходными значениями каталога. Названия, изменённые администратором, инструкции оплаты, имена, реквизиты, исходные медицинские документы, записи врачей и сохранённые ответы модели остаются в исходном виде. Переключатель интерфейса не изменяет клиническую информацию или историю проверок. Машинный JSON-экспорт сохраняет стабильные имена полей; существующий PDF-экспорт формируется backend отдельно на английском языке.

## Проверки

Из каталога `frontend`:

```powershell
npm.cmd run build
npm.cmd run lint
npm.cmd test
npm.cmd run test:e2e
```

`localization.test.ts` проверяет совпадение ключей, непустые значения, параметры подстановки, все явные вызовы `t()` в исходниках, динамические статусы, роли и склонения. `localeBehavior.test.ts` проверяет даты, сохранение языка, API-ошибки и сохранность пользовательских текстов. `LocalizedForm.test.tsx` проверяет смену языка уже показанных ошибок без повторной отправки и без изменения значений. Браузерные сценарии находятся в `e2e/localization-landing.spec.ts` и `e2e/localization-workspace.spec.ts`.
